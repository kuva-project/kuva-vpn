# سیاست حفظ حریم خصوصی — KUVAVpn

_آخرین به‌روزرسانی: ۲۰۲۶-۱۱-۰۹_

KUVAVpn یک کلاینت VPN متن‌باز برای اندروید است که با هسته‌ی Xray کار می‌کند.
این سند دقیقاً توضیح می‌دهد اپ چه فعالیت شبکه‌ای انجام می‌دهد و چه داده‌ای ذخیره می‌کند و برای کلاینت منتشرشده در این مخزن معتبر است.

**خلاصه: KUVAVpn نه بک‌اند دارد، نه سیستم اکانت، نه SDK آنالیتیکس و نه تلمتری. توسعه‌دهنده هیچ داده‌ای دریافت نمی‌کند. هر درخواست شبکه‌ای که اپ می‌زند، یا خود تو راه می‌اندازی، یا برای اجرای ویژگی‌هایی که استفاده می‌کنی لازم است — و مستقیم از دستگاه تو به سرویس مربوطه می‌رود.**

## ۱. داده‌هایی که اپ جمع نمی‌کند

- هیچ داده‌ی شخصی (نام، ایمیل، تلفن، شناسه)
- بدون آنالیتیکس، گزارش کرش یا SDK ردیابی (بدون Firebase، بدون Google Analytics، بدون کتابخانه‌ی تبلیغات)
- بدون شناسه‌ی تبلیغاتی
- بدون تاریخچه‌ی مرور، درخواست DNS یا محتوای ترافیک — اینها داخل تانل رمزنگاری‌شده به سرور VPN که **خودت** تنظیم کرده‌ای می‌روند؛ اپ هیچ‌جای دیگر ذخیره یا ارسالشان نمی‌کند
- بدون مخاطبین، عکس، رسانه یا فایل

## ۲. داده‌هایی که روی دستگاه تو ذخیره می‌شوند (هرگز برای توسعه‌دهنده ارسال نمی‌شوند)

| داده | کجا | محافظت |
|---|---|---|
| پروفایل‌های کانفیگ (آدرس سرور، پورت، UUID/رمز) | دیتابیس محلی Room | UUID و رمزها با AES-256-GCM و کلید Android Keystore رمز می‌شوند |
| نشانی‌های سابسکریپشن | دیتابیس محلی | رمزنگاری مثل بالا |
| تنظیمات (تایم‌اوت، MTU، حالت روتینگ، اپ‌های انتخابی) | DataStore محلی | فقط روی دستگاه |
| نتایج پینگ/تست سرعت | دیتابیس محلی | فقط روی دستگاه |
| لیست اپ‌ها (برای split tunneling) | خوانده‌شده با PackageManager | فقط برای نمایش لیست روتینگ هر اپ؛ هرگز آپلود نمی‌شود |

حذف (Uninstall) اپ همه‌ی موارد بالا را پاک می‌کند.

## ۳. درخواست‌های شبکه‌ای اپ و دلیلشان

همه‌ی اینها درخواست مستقیم دستگاه به سرویس هستند. هیچ‌کدام از سروری که توسعه‌دهنده اجرا کرده باشد عبور نمی‌کنند — چون توسعه‌دهنده سروری ندارد.

| هدف | سرویس‌های تماس‌گرفته‌شده | چه زمانی |
|---|---|---|
| تانل VPN | سرور(های) داخل کانفیگ/ساب‌های **خودت** | وقتی وصل می‌شوی |
| رفرش سابسکریپشن | نشانی سابی که **خودت** وارد کرده‌ای | وقتی ساب اضافه/رفرش می‌کنی |
| کشف کانفیگ رایگان | مخازن عمومی GitHub raw (freefq، Pawdroid، mahdibland، MhdiTaheri، Au1rxx، hamedcode)، `radarhub.top`، پیش‌نمایش کانال‌های عمومی تلگرام (`t.me/s/…`) | وقتی تب «کانفیگ‌های جدید» را استفاده می‌کنی یا رفرش می‌زنی |
| پینگ کانفیگ (تأخیر) | هندشیک TCP به آدرس سرور هر کانفیگ | وقتی پینگ می‌گیری |
| تست سرعت | `speed.cloudflare.com` (`__down`/`__up`)، روت‌شده **از طریق کانفیگ انتخابی** | وقتی تست سرعت می‌گیری |
| چک اتصال | `www.gstatic.com/generate_204` | برای اطمینان از اینکه کانفیگ واقعاً ترافیک رد می‌کند |
| تشخیص IP/کشور خروجی | `api.ip.sb`، `ipapi.co`، `ipwho.is`، تصاویر پرچم از `flagcdn.com` | بعد از اتصال، برای نمایش IP ظاهری و پرچم کشور |
| GitHub API | `api.github.com` | لیست مخازن عمومی منابع کانفیگ |

منابع کانفیگ رایگان اشخاص ثالث هستند. کانفیگ‌های گرفته‌شده از آنها به سرورهایی اشاره دارند که ناشرشان اداره می‌کند — متناسب با آن برخورد کن.

## ۴. پرمیشن‌های اندروید و دلیلشان

| پرمیشن | چرا |
|---|---|
| `INTERNET`، `ACCESS_NETWORK_STATE` | شبکه‌ی اصلی و اتصال مجدد هنگام تغییر شبکه |
| `FOREGROUND_SERVICE` (+ `SPECIAL_USE`) | زنده نگه داشتن تانل با نوتیفیکیشن وضعیت |
| `POST_NOTIFICATIONS` | نوتیفیکیشن وضعیت اتصال (اندروید ۱۳+) |
| `RECEIVE_BOOT_COMPLETED` | اتصال مجدد اختیاری بعد از ریبوت |
| `QUERY_ALL_PACKAGES` | لیست روتینگ هر اپ (split tunneling)؛ لیست روی دستگاه می‌ماند |
| اتصال `VPN_SERVICE` | برقراری اینترفیس TUN |

اپ هیچ پرمیشن مکان، مخاطبین، حافظه، دوربین یا میکروفون نمی‌خواهد.

## ۵. اپراتور VPN تو چه می‌بیند

وقتی وصل می‌شوی، ترافیک از سرور VPN که تنظیم کرده‌ای خارج می‌شود. اپراتور آن سرور (پنل خودت، ارائه‌دهنده‌ی ساب، یا ناشر کانفیگ رایگان) می‌تواند مقصد ترافیک را ببیند، مثل هر اپراتور VPN دیگری. KUVAVpn هیچ شناسایی اضافه‌ای جز چیزی که پروتکل کانفیگ لازم دارد اضافه نمی‌کند (مثلاً UUID تو که سرور به هر حال باید داشته باشد).

## ۶. کودکان

اپ متوجه کودکان زیر ۱۳ سال نیست و از هیچ‌کس داده جمع نمی‌کند، پس چیزی برای حذف از طرف آنها وجود ندارد.
